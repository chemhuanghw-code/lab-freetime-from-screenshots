# 课表截图 → 人员空闲表 / 排期 PDF

## 极简用法（默认走这条）

截图放进一个目录（文件名带姓名）→ 依次跑三段：

```powershell
$env:PYTHONIOENCODING='utf-8'; [Console]::OutputEncoding=[Text.Encoding]::UTF8
$py='C:\Users\DRBINGBING\.workbuddy\binaries\python\versions\3.13.12\python.exe'
$S='C:\Users\DRBINGBING\.workbuddy\skills\lab-freetime-from-screenshots\scripts'
$D='out'

# 1) 截图 → 数据（--week-no 必传，用于 PDF 文件名）
& $py "$S\shots_to_json.py" "<截图目录>" -o "$D\timetable_data.json" `
      --week-no 3 --week 9.14-9.20 --monday 9.14 --debug

# 1b) 先核对表头星期顺序！有「周日在前」的图就补 --first-day（见「关键坑 9」）
& $py "$S\shots_to_json.py" "<截图目录>" -o "$D\timetable_data.json" `
      --week-no 3 --week 9.14-9.20 --monday 9.14 --first-day "某人=周日"

# 2) 数据 → 表格六件套
& $py "$S\render_freetime.py" "$D\timetable_data.json" -o $D

# 3) 数据 → 最终 PDF（--name 不传则自动拼 第N周_日期段_人员空闲与学时统计）
& $py "$S\render_report_pdf.py" "$D\timetable_data.json" --groups groups.json -o $D
```

**PowerShell 的 stdout 经常返回空** → 一律 `*>&1 | Out-File -Encoding utf8 out.txt` 再用 Read 读。

## 交付前必做：核对表头星期顺序

像素分析只认「第几列」，**认不出那是星期几**。所以每批截图都要裁出日期行肉眼过一遍：

```python
# 裁日期行（蓝底白字那一行），2 倍放大后 Read 看
im.crop((0, int(H*0.19), W, int(H*0.30)))   # 比例随机型浮动，0.10~0.32 之间试
```

- 大多数图首列是「周一 14」→ 默认即可，不用传 `--first-day`。
- **少数图首列是「周日 13」、末列才是「周六 19」**（同一批里实测出现过 1/7 张）→
  必须传 `--first-day "该图=周日"`，否则这个人的整周错位一天，且不会报任何错。
- 传法：`--first-day "某人=周日"`（按文件名关键词命中，多个用逗号隔开）；
  `--first-day 周日` 表示整批都周日在前。只有异常图才写，正常图别写。

## 硬性约定（改代码时别退回去）

| 项 | 值 |
|---|---|
| 节次 | 白天 4 大节 + 晚上 2 大节（第 9~12 节）。截图只有 5 行时，第 5 行「晚上」覆盖大节 5、6 |
| 配时间 | 上午 08:00 / 下午 14:00 / 晚上 18:30–22:00（**晚上 4 节课、6 到 10 点**，别写成 1 格） |
| 学时 | 1 大节 = 2 学时；全周 = 7 天 × 12 节 = **84 学时** |
| 学时三段 | **工作日白天 40 / 周末 16 / 晚修 28，必须分开计**，不许并成一条 |
| 单元格 | xlsx / html / png 一律水平 + 垂直居中（用户明确要求） |
| PDF 命名 | `第N周_日期段_人员空闲与学时统计.pdf`，`--name` 不传时自动拼 |
| PDF 页 | **默认只出 P3、P4**（用户自己排班，不要建议页）；`--pages all` 才出 1–4 |
| 首列星期 | 默认「周一在前」；个别图是「周日在前」，用 `--first-day "关键词=周日"` 纠正 |
| 姓名配色 | 每人固定一色 + 加粗，P3/P4 一致；**不含红色系**；想钉死某人的颜色改脚本里 `PERSON_FIXED`；P4 字 8.4 |

## 关键坑

1. **只用饱和度判彩色** `(max-min) > 30 and max > 60`。这批 App 色块是浅色系、最大通道常达 250~252，
   「接近纯白就排除」会把色块整片误杀，只剩零星几格。
2. **左侧标签列宽固定 0.10W**，不能用深色像素中位数猜（会得 0.148W，整表列错位）。
3. **列数自适应 1~7**，用表头白字簇间距反推；只截到周五的图若按 7 列分会横向拉错。
4. **底部「无课表课程」面板是饱和蓝**，会污染最后一行 → 先求面板顶边、裁掉再采样。
5. 只记「有课」，空闲由渲染器取补集。**不要手工推交集**，5 组 30+ 格人脑必错。
6. 截图目录里混着统计表/汇总表时，按文件名跳过。
7. **同班同学课表一致**：直接复制那个人的 `busy` 数组，别再要截图。
8. **PDF 报 `PermissionError [Errno 13]` = 用户正开着那份 PDF**。别硬顶：换个名字把成果落地，
   让用户关掉预览后再跑一次原名字覆盖（第二次通常成功）。
9. **星期排列可能是「周日在前」**（实测第三周 7 张里有 1 张）。这种图首列是「周日 13」、
   末列「周六 19」，而正常图首列「周一 14」、末列「周日 20」。列序不同 → 该人整周错位一天，
   且**不会触发任何自检告警**（人数、学时、空率全都自洽）。只能靠裁日期行肉眼核对发现。
   纠正：`--first-day "姓名关键词=周日"`。另外注意 `--first-day` 里 `周X` 会被规范化成 `星期X`
   （App 上写「周日」，DAYS 里存「星期日」），直接传「周日」即可。
10. **debug 打印的行是「第几列」不是「星期几」**，别拿它去对星期；对不上时先查第 9 条。
11. 判断某格 `busy` 属于哪个「大节」，看 `frac` 分数：偏低的（约 0.55~0.6，浅色块如暗紫）
    会在 debug 里显示成 `0.00` 却仍被写入 JSON —— 阈值 `BUSY_THR=0.55` 是准的，别改。

## 自检

`render_freetime.py` 打印空闲人数矩阵、推荐时段 TOP3 和「需核对」项：某时段 ≥3 人却 0 人空闲 → 冲突；
**某人整周无课 / 整周满课 → 几乎肯定是版面定位失败，回看截图**。交付前挑 2–3 人肉眼对一遍。

⚠ 自检**查不出**星期的列序错位（见「关键坑 9」），所以「核对表头星期顺序」是独立的一步，不能省。

## 排实验（可选；P1/P2 页也用它）

```powershell
& $py "$S\schedule_experiments.py" "$D\timetable_data.json" `
      --groups groups.json --hoods hoods.json -o $D
```

- 并行硬约束：① 组内不撞人 ② 不抢同一个通风橱。**通风橱通常不是瓶颈，跨组的人才是**
  （实测 5 组只需 3 个时段，串行要 5 个）。
- 求解用 `best_plan()`（先枚举"用哪 k 个时段"再在集合内分配，秒级）；**不要用 `solve()`**
  （候选一放开到周末+晚修就指数爆炸，还会被 `MAX_SOLUTIONS` 截断而错过最优解）。
- 排实验**不要加 `--drop-empty-slots`**——它会把"全周没人上课"的晚上整行删掉，而晚上最容易凑齐。
- `--slots 1,2,3,4` / `--day-set 1,2,3,4,5`（**周日 = 7**）限定范围。
  典型三方案各跑一次：A 工作日白天 / B 全部晚修 / C 周末集中。
- 只有 2 天的方案里，跨 3 组的人**必然**有一天跑两组（抽屉原理），别承诺"零冲突"。
- **交接时一定要问清一轮实验要几个大节**——跨 2 个大节则"单格空闲"不够用，得重算连续时段。

`groups.json`（第一个名字即组长；**换成自己的组名与成员**）：

```json
{"组A": ["甲一", "乙二"], "组B": ["丙三", "丁四", "甲一"],
 "组C": ["戊五"], "组D": ["己六", "丙三"], "组E": ["庚七"]}
```

`hoods.json`（可选，不需要工作位就填 `null` 或删掉该文件；化学实验室里工作位＝通风橱）：

```json
{"hoods": ["工作位1", "工作位2", "工作位3"],
 "map": {"组A": "工作位1", "组B": "工作位2",
         "组C": "工作位3", "组D": null, "组E": null}}
```

## 可视化选型

| 想回答 | 用哪张 |
|---|---|
| 某时段都有谁 | 名单版表格（`人员空闲表.png` / xlsx） |
| 什么时候人最齐 | 热力图（`_热力图.png`，橙框标最推荐 2 个时段） |
| 谁最忙 / 谁最闲 | 人员矩阵（`_人员矩阵.png`，右下给「空闲/20」排名） |

矩阵图色块定死：空闲 `#CDEBD4`、有课 `#C8CFD7`。**别用绿/红**，会跟"涨红跌绿"直觉冲突。

## 版式经验（改 PDF 时照抄）

- 网格格子里**不要塞名单**（指 P2 排期网格），只放「组名 + 人数 + 通风橱」，名单移到网格下方图例；
  P4 空闲表例外（那里的名单就是主体）。否则一格两组时三行必然重叠。
- **别用 `axp.legend`**：`bbox_to_anchor` 在横向条形图里会压住最后一根柱，改在主 ax 上手画色块。
- **中文字宽 ≈ 字号**：每行字数 `= int(可用宽in / (fs/72))`，不要用「宽度×6.9」这类固定系数
  （会把 7 个人的格子截断成 `…`）。
- 表格走 `kv_table()`（支持 `col_style` 整列上色），网格走 `draw_week_grid()`，姓名上色走 `draw_names()`。
- `--preview <目录>` 把每页另存 PNG，**用 Read 看 PNG 核对版式，别指望直接读 PDF**。

## 文件

- `shots_to_json.py` 截图目录 → JSON（纯像素分析，**不写 OCR**；支持一张图多人 `A-B-C-3.jpg`；
  `--first-day` 纠正「周日在前」的列序）
- `render_freetime.py` JSON → PNG / HTML / XLSX / CSV / 热力图 / 人员矩阵（默认六件套）
- `schedule_experiments.py` 排期报告 + `实验排期建议.png`
- `render_report_pdf.py` 最终 PDF（`--pages` 默认 3,4），内含姓名配色与 `kv_table`
- 依赖 `numpy` `Pillow` `openpyxl` `matplotlib`

## 核心认知

**不写 OCR、不逐张肉眼读。** 这类 App 的「有课」格子都填了彩色块，而生成空闲表根本不需要课程名，
所以整条链路是全自动、零识别误差的——只有自检报警时才回看截图那一两格。
