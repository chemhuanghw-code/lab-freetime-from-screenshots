# 课表截图 → 人员空闲表 / 排期 PDF

给一批学生课表截图（手机课程表 App 的周视图），自动汇总出「谁在哪个时段有空」，
并生成一张可直接打印、发群的 PDF。

## 装上（30 秒）

1. 把整个 `lab-freetime-from-screenshots` 文件夹放到：
   `C:\Users\<你的用户名>\.workbuddy\skills\`
2. 重启 WorkBuddy。

装好后不用记命令，直接跟它说一句话就行。

## 用

**方式一（推荐）**：在 WorkBuddy 里说

> 课表截图在 `D:\课表` 目录，汇总成空闲表，第 3 周，9.14-9.20

它会把整条流程跑完，产出一份 `第3周_9.14-9.20_人员空闲与学时统计.pdf`。

**方式二（不想开 WorkBuddy）**：把截图放进本目录下的 `shots` 文件夹，双击 `一键出表.bat`，
按提示输入周次和日期即可。结果出在 `output` 文件夹。

也可以直接带参数调用（适合脚本/快捷方式）：

```
一键出表.bat  "D:\课表\第三周"  3  9.14-9.20  9.14
              └ 截图目录      └周次 └日期段   └周一日期
```

## 截图怎么准备

- 一个学生一张图，**文件名带姓名**：`张三-3.jpg`
- 同一张图多个人（同班课表一样）：`张三-李四-王五-3.jpg`
- 截图目录里混着汇总表也没关系，脚本按文件名自动跳过
- 周末和晚修默认视为全员空闲，截图里没有这两列是正常的

## 出来什么

| 文件 | 用途 |
|---|---|
| `第N周_日期段_人员空闲与学时统计.pdf` | **最终交付物**：空闲学时统计 + 全周空闲表（7 天 × 6 大节） |
| `人员空闲表.png` | 名单版表格，直接发群 |
| `人员空闲表_热力图.png` | 什么时候人最齐 |
| `人员空闲表_人员矩阵.png` | 谁最忙、谁最闲 |
| `人员空闲表.xlsx` / `.csv` / `.html` | 可编辑 / 可转 PDF |
| `timetable_data.json` | 中间数据，可手改后重跑 |

## 排实验（可选）

如果还要排实验分组，把 `groups.json` 改写成你自己的分组（第一个名字是组长）：

```json
{"组A": ["甲一", "乙二"], "组B": ["丙三", "丁四", "甲一"],
 "组C": ["戊五"], "组D": ["己六", "丙三"], "组E": ["庚七"]}
```

再说一句「按分组排实验」，会额外输出排期建议（并行、最少时段、跨组冲突检查）。

需要限制工作位（化学实验室就是通风橱）时，在 `hoods.json` 里写：

```json
{"hoods": ["工作位1", "工作位2", "工作位3"],
 "map": {"组A": "工作位1", "组B": "工作位2", "组C": "工作位3",
         "组D": null, "组E": null}}
```

## 环境要求

`numpy`、`Pillow`、`openpyxl`、`matplotlib`。WorkBuddy 自带的 Python 已装齐；
用系统 Python 的话先 `pip install numpy pillow openpyxl matplotlib`。

## 想分享给别人 / 上传 GitHub？

这个工具会碰到真实姓名，所以**分享前先换掉示例**：

1. `groups.json`、`hoods.json` 里的组名、人名、工作位名 → 改成 `张三 / 李四 / 组A` 这类占位；
2. 本目录下 `shots/` 里的截图、`output/` 里的 PDF/Excel → 全部删掉（`.gitignore` 已默认忽略）；
3. 别把带真实数据的 `timetable_data.json` 一起传上去。

脚本本身不需要改：姓名、分组、工作位都是从 `groups.json` / `hoods.json` / 截图文件名读进来的，
代码里没有写死任何人。
